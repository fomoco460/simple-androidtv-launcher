# Simple Android TV Launcher

I saw all the vibe-coded TVs, but I have a Roku TV with a Chromecast 4K hooked up to it, so I made this super simple launcher for it. It is 100% generated by Google AI Studio, but it works perfectly for my setup.

## Features
* Lightweight, minimal interface.
* Designed specifically for Chromecast with Google TV 4K.
* Fully generated using AI.

## Installation & Setup

### 1. Sideload the APK
Download `clean-launcher-tv.apk` from the [Releases](https://github.com/fomoco460/simple-androidtv-launcher/releases) page and sideload it (e.g. `adb install clean-launcher-tv.apk`, or an app like "Send files to TV").

> APKs are published only through GitHub Releases and are never committed to the repository.

### 2. Grant required permissions (ADB)
To intercept the remote's Home button the launcher runs as an accessibility service. Connect to your Chromecast over ADB and run:

```powershell
adb shell appops set com.chromecast.cleanlauncher ACCESS_RESTRICTED_SETTINGS allow
adb shell settings put secure enabled_accessibility_services com.chromecast.cleanlauncher/com.chromecast.cleanlauncher.LauncherAccessibilityService
adb shell settings put secure accessibility_enabled 1
```

**Optional:** allow the in-app "restore accessibility service" button to work by granting write access to secure settings once:

```powershell
adb shell pm grant com.chromecast.cleanlauncher android.permission.WRITE_SECURE_SETTINGS
```

### Recovery: if the Home button stops working
If the launcher crashes, is removed badly, or you just want the stock Home button back, turn the accessibility service off over ADB:

```powershell
adb shell settings put secure enabled_accessibility_services ""
```

You can also uninstall it: `adb uninstall com.chromecast.cleanlauncher`.

## Building from source

Requirements: Node.js 20+, a JDK, and (on Debian/Ubuntu) the Android build tools that `scripts/build-apk.sh` installs automatically with `apt-get`.

```bash
npm install
npm run lint     # type check
npm run build    # web bundle only (dist/)
```

### Build a signed APK
Android only installs an update over an existing app if it is signed with the **same key**, so create one release key once and reuse it. Keep it outside the repo and back it up.

```bash
./scripts/make-keystore.sh            # one time; creates ~/.clean-launcher/release.keystore

export KEYSTORE_PATH="$HOME/.clean-launcher/release.keystore"
export KEYSTORE_PASS='your-keystore-password'
export KEY_ALIAS=cleanlauncher
npm run build:apk                     # -> release/clean-launcher-tv-<version>.apk
```

The version comes from `package.json`. Upload the resulting APK to a GitHub Release as `clean-launcher-tv.apk`.

## Notes
* The launcher shows each app's own icon taken from the device. Third-party brand artwork is not bundled.
* Settings (app row, wallpaper, etc.) are stored in the WebView's local storage. Uninstalling the app erases them.
